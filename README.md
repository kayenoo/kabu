# КАБУ live

Игра для аудитории, как Kahoot: ведущий выводит QR на экран, люди сканируют его, вводят имя и попадают в лобби. Потом их случайно раскидывает по столам по 4 человека (остаток по 3), и каждый играет в КАБУ со своего телефона.

- `/host` — экран ведущего: QR, PIN, список игроков, столы и лидеры
- `/` — телефон игрока

## Запуск на Render (бесплатно, ~10 минут)

1. Залей эту папку в новый репозиторий на GitHub (можно через github.com → New repository → «uploading an existing file», перетащить все файлы, кроме `node_modules`).
2. Зайди на render.com → New → Web Service → подключи этот репозиторий.
3. Настройки: Runtime **Node**, Build Command `npm install`, Start Command `npm start`, тип **Free**.
4. После деплоя открой `https://<твой-адрес>.onrender.com/host` на ноутбуке, подключённом к проектору.

Бесплатный Render засыпает, если на сайт 15 минут никто не заходил, и потом просыпается около минуты. Открой `/host` за пару минут до начала.

## Свои дизайны карт

Положи картинки в `public/cards/` (PNG, пропорция 5:7, например 500×700):

- масти: S ♠, H ♥, D ♦, C ♣ → `AS.png`, `2S.png` … `10H.png`, `JD.png`, `QC.png`, `KH.png`
- джокеры: `JK1.png`, `JK2.png`
- рубашка: `BACK.png`

Если какой-то картинки нет, вместо неё показывается обычная нарисованная карта. Очки и способности рисуй прямо на карте, поверх дизайна ничего не добавляется.

## Локальная проверка

```
npm install
npm start
```

Открой `http://<IP-ноутбука-в-сети>:3000/host` (не `localhost`, иначе QR будет вести на localhost). Телефоны должны быть в той же Wi-Fi сети.

## Настройки

В начале `server.js`: `TURN_MS` — время на ход (45 с), `PEEK_MS` — время на просмотр 2 карт в начале (25 с). Если игрок не успел сходить, за него автоматически тянется и сбрасывается карта. Если игрок отключился, его ход пропускается через 4 с.
